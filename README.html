🤖 AI 招聘评估系统

不是"更好的招聘工具"——是把"标签筛选"替换为"理解"，让 AI 的招聘判断可追溯、可验证、可质疑。

FastAPI LLM 语音交互 可验证 理解替代筛选

🎯 为什么招聘流程需要重构

传统招聘流程的问题不是效率低——是方向错了。

📝 JD ≠ 需求

JD 是写给外面看的文案，不是真正的人才需求。写 JD 的人和最终拍板的人对"要什么样的人"的理解经常不一致，这个问题通常到面试结束才暴露。

🏷️ 标签筛选丢失信息

HR 不懂业务，只能看标签。一个人把自己压缩成一页纸的简历，然后被另一个不懂业务的人用关键词扫一遍——每一步都在丢信息。

🔍 判断不可追溯

面试结论往往是一句"感觉不太合适"，说不出具体依据。如果换一个面试官，结论会不会不同？——无人能答。

💡 核心思路：用理解替代筛选

不是用 AI 加速现有流程，而是重构流程本身——从理解需求开始，到理解人，再到做出可验证的匹配判断。

🎯

理解需求

需求是内部的、结构化的、往往连提需求的人自己都没完全想清楚的东西。Agent 通过对话式追问，把模糊的招聘需求"逼"出来，生成结构化人才画像。

  • JD 解析 + 对话澄清
  • 信号维度与评估标准
  • 必要条件 vs 加分项
👤

理解人

不是提取关键词、不是贴标签。从多种信号里读出这个人做过什么、擅长什么、信号强在哪里弱在哪里，并识别信息盲区。

  • 经历 vs 声明分离
  • 多源信息融合
  • 信息缺口自动标记
✅

可验证的匹配

叙事性判断——不打分、不出雷达图。每个结论绑定原始证据，逻辑链可追溯。三层验证框架确保判断质量。

  • 证据链完整性检查
  • 判断稳定性测试
  • 候选人区分度检验

🔬 核心创新：三层可验证性

🔗

证据链验证

每条判断结论必须绑定至少一条原始证据。系统自动检查推理链是否成立，无法找到支撑证据的判断标记为"无依据"。

  • 判断："自驱力强"
  • 依据："自己用 Python 写了自动化脚本处理社团报名表"
  • 验证：✅ 主动发现问题 + 独立解决 + 实际影响
📊

稳定性测试

同一候选人多次面试，对比核心判断的一致性。区分"合理修正"和"随机波动"，输出稳定性报告。

📈

区分度检验

检验系统对不同候选人的评估是否存在有意义的差异，识别"无效评估"维度。

🎯 三大优化方向

🧬 从画像推理成长性——避免量化打分

不量化、不打分，而是从五个维度进行叙事性成长性分析：

📈 学习轨迹

技能宽度vs深度的变化趋势

🔥 挑战偏好

是否主动选择有难度的项目

🔄 适应能力

跨技术栈/跨行业的迁移经验

⚡ 成长速度

同等年限内的实际成长速率

🚀 自驱力

开源贡献、技术博客等额外信号

🔗 画像与简历结果对齐——双向验证

画像的信号维度作为评估基准框架，简历分析结果按同一套维度组织。面试时对两者都存在的信息进行交叉验证——如果简历说"精通 Python"但面试中连基础问题都回答不清，系统标记为"声明与表现不一致"。最终报告对齐所有来源的判断，标注置信度。

🎯 需求场景驱动——以公司实际缺口为起点

系统内置五个典型需求场景，贯穿整个面试闭环：

场景公司缺口考察重点
🔧 技术深耕技术领域深度不足技术深度与架构能力
🌐 技术拓展需要拓展新技术栈学习能力与技术广度
👥 团队管理缺少技术 leader领导力与团队协作
📐 质量提升项目质量亟待提升工程化与质量意识
💡 业务创新需要开拓新业务方向业务理解与创新能力

公司缺口 → 选择场景 → 场景化画像 → 场景化面试 → 场景化评估 → 是否匹配需求

📦 五大模块

🎯

需求定义 Agent

通过 LLM 对话式交互，把模糊的招聘需求"逼"出来。Agent 主动追问暴露矛盾，生成结构化人才画像。

  • JD 解析与结构化提取
  • 对话式澄清与追问
  • 画像保存后同步面试库
📄

简历分析

上传 PDF/Word 简历，LLM 语义分析，分离"能力声明"与"客观经历"，识别信息盲区与外部足迹。

  • 支持 PDF、Word，图片 OCR
  • 经历 vs 声明信号强度标注
  • 自动抓取 GitHub、博客足迹
🎤

AI 面试引擎

语音优先交互：AI 语音提问 → 候选人语音回答 → LLM 动态追问。Web Audio API 实时采集，VAD 静默自动分段。

  • 阿里云 TTS 播报 + ASR 识别
  • PCM → WAV 实时编码上传
  • 每问题最多追问 2 次
📋

综合评估

叙事性评估报告——不打分、不出雷达图。每个判断绑定原始证据，结论可跳转到面试原文。

  • 信号提取（按画像维度展开）
  • 风险与顾虑标注
  • 适合/不适合二分结论
🔍

判断质量验证

三层验证框架：证据链完整性检查、判断稳定性测试、候选人区分度检验。输出质量报告。

  • 推理链自动验证
  • 多次面试一致性对比
  • 跨候选人区分度分析

⭐ 核心创新点

🧠 多 LLM 协同架构

画像、简历、面试三个模块使用独立的 LLM 配置，各模块可独立切换模型和参数，互不干扰。面试模块支持在前端页面实时切换 LLM 配置。

🎙️ 语音优先面试

区别于传统文本面试，实现了完整的语音问答流程——AI 语音提问、候选人语音回答、LLM 动态追问，更接近真实面试场景。

📋 数据驱动可追溯

从画像生成到最终评估，每一步的数据都持久化保存。评估结果可追溯到具体的问答记录，每条判断绑定原始证据，确保可验证性。

🔍 判断质量验证

三层验证框架（证据链/稳定性/区分度）自动检验 AI 判断的可靠性，输出质量报告。这是区别于所有现有工具的核心创新。
